# BDL 0.13.1

- 桌面和手机解析页使用同一个按钮暂停和继续。继续时保留已完成的链接和页数，补完当前批次。
- 在「设置 → 链接与解析」中可分别设置每次解析的目标条数和请求间隔。单次默认 50 条，按来源整页加载。
- 桌面下载队列和命令行提供更具体的错误码和处理建议，方便定位问题和反馈。
- 选择 GitHub 更新源时，客户端直接从 GitHub 检查更新。

macOS 安装包使用 ad-hoc 签名，未经 Apple 公证。首次打开请参阅 [macOS 安装指引](https://github.com/Yuelioi/bdl/blob/v0.13.1/README.md)。
