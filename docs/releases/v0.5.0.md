## v0.5.0：独立 CLI

- 新增 Windows x64、Linux x64、macOS Apple Silicon / Intel 命令行包，文件名为 `bdl-cli-0.5.0-<平台>`，附 SHA-256 校验文件。下载需要单独安装 FFmpeg。
- 支持解析、指定分 P / 集数下载、列表分页、JSON 输出、Cookie 文件、短链接及检查点恢复。下载必须指定 `--parts`、`--items` 或显式 `--all --state`，不会默认下载整个列表。
- 增加实际 HTTP 请求预算、同一系统用户跨进程限流与冷却、检查点排他锁；支持有限临时错误重试及 404/410 媒体地址刷新。

### 风控说明

工具的节流措施不能保证不触发 Bilibili 风控，也不是平台公布的安全阈值。默认每次命令最多 50 个解析操作、100 次解析 HTTP 请求；同一系统用户共享每 60 分钟 7200 次请求预算，默认每 0.5 秒最多发起一次请求（每秒最多 2 次），不再每 10 次强制休息。签名请求、短链接与重试也计入 HTTP 预算。

遇到 403/412/429、已知限制码或验证提示会立即停止，记录至少 5 分钟冷却，并遵从更长的 Retry-After；不会自动重试限制响应或切换备用 CDN。冷却结束不代表限制解除，请勿循环重启绕过停止。CDN 数据传输、桌面端、其他工具及其他系统用户不共享该解析请求预算。

受限内容仍需账号自身访问权限。各类来源的账号权限行为尚未逐一线上验收；检查点支持手动恢复，当前没有常驻后台任务队列。

用法见 [CLI 指南](https://github.com/Yuelioi/bdl/blob/v0.5.0/docs/CLI.md)。例如：

```sh
bdl download BV1ZA411g7Sb --parts 1,2 -o downloads --state .bdl/ae.json
```
