# BDL v0.10.0

## 桌面与 Android 界面更新

- 重新整理解析、内容库、收藏夹详情、传输、设置和关于页面，统一浅深色主题、B 站粉色强调、字号、圆角和控件间距。
- 解析列表增大缩略图，保持紧凑行高；手机底部直接展示当前下载预设、调整和下载操作。
- 手机传输列表改为两行，统一封面、状态、进度和速度的位置，减少排队与已完成任务的空白。
- 标签页、选择器、按钮和弹窗统一使用组件库及共享封装，修正标签指示线、分页底色、选中留白和滚动区间距。

## 预设与设置

- 下载设置优先选择预设，支持下载时新增或编辑；移除下载弹窗中的调度入口。
- 下载预设与命名预设集中在设置页管理，支持直接新增、编辑、复制、删除和设为默认；模板变量放入编辑器。
- 设置按下载与保存、画质与编码、预设管理、应用更新、网络与维护分组，相关说明按需查看。
- 预设编辑器直接展开转换与封装选项；自动识别剪贴板失败时不再反复打断操作。

## 画质、音质与编码优先级

- 清晰度、音质、视频编码和音频编码提供完整固定候选，可直接调整优先级，无需逐项新增或删除。
- 下拉列表同步编排顺序；“最佳可用”按编排选择，手动指定清晰度继续按指定档位处理。
- “仅 SDR”独立作为动态范围筛选，画质与编码提供操作说明。
- 新任务记录音频编码，链接刷新后继续匹配对应轨道。缺少音频编码记录的旧任务需要刷新链接时，会提示重新创建。

## 更新来源

- 从官方软件站读取当前平台的来源，分别展示 GitHub、GH-Proxy、GHFast 和已提供的夸克入口。
- 自定义加速独立选择，空地址明确提示填写；官方来源读取失败可重试，已撤下的来源需要重新选择。
- 桌面应用内安装继续校验 BDL 更新签名；Android 在浏览器下载 APK 后手动安装。

## 下载可靠性

- 修复分段续传检查点、队列提交、账号切换竞态、输出路径冲突和更新权限问题。
- 无法确认分段布局的旧检查点仅重新下载受影响的未完成资源，保留已完成文件及任务记录。

## 安装说明

- Windows、macOS、Linux 请下载对应平台安装包；CLI 包单独提供。
- macOS 包采用 ad-hoc 签名，未经 Apple 公证。首次启动请按 README 的“右键打开”或“隐私与安全性 → 仍要打开”指引操作。
- Android ARM64 APK 为开发预览，已内置 FFmpeg；请使用本 Release 中项目签名的安装包。
