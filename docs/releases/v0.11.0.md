# BDL 0.11.0

- 桌面版新增「设置 → AI 接入」，可用 MCP 解析和翻页选集、浏览收藏夹、按预设下载、管理传输任务和调整常用设置。
- 桌面解析入口与结果页分开，返回时保留输入和选择。长合集可继续解析、解析全部或在后台下载全部。
- 整理桌面内容库、传输、设置和关于页，设置按用途分区，失败任务详情提供对应的恢复操作。
- 调整解析节奏预设，排队任务至少间隔 5 秒启动。下载总限速提供 3、10 和 30 MB/s 预设，也可以自定义。
- Android 简化解析、选集和下载操作，系统返回手势优先返回上一级。
- 修复 Android 导出文件被移动或删除后，删除下载任务无法清理应用内文件的问题。
