## v0.6.0

- 新增面向 Android 的独立手机界面，解析、内容库、传输、设置与“我的”共用现有业务状态，但采用底部导航、紧凑两行列表、深色模式和手机专属操作面板；桌面界面保持原有工作流。
- 完善 Android ARM64 下载闭环：安全保存账号凭据，通过系统目录导出文件，使用内置 FFmpeg 合并音视频，并在任务运行期间提供前台执行与通知支持。
- 加固下载恢复与过期链接处理：CDN 不支持 HEAD 时自动回退到 Range 探测，404 资源会自动刷新下载地址并最多重试三轮，减少需要用户手动点击“重试”的情况。
- 任务列表持久显示视频封面与时长，并明确区分“下载视频中”“下载音频中”和“合并中”；已完成任务可直接从封面播放，暂停、继续和重试操作也统一收进封面。
- 重构解析、内容库、传输和设置页面的共享逻辑，统一分页、批量选择、下载设置与任务操作；手机内容列表采用小圆角、统一字号和高密度布局。
- 修复 Android 原生合并错误无法正确回传、短链接入口绕过展开流程、特定 CDN 请求长度失败，以及手机操作面板偏移、横向溢出和分页遮挡等问题。

### Android 说明

Android 版本目前提供 ARM64 开发预览包，并内置 FFmpeg。安装包仅在发布仓库已配置固定 Android 签名密钥时随 Release 上传；否则本次 Release 只提供桌面与 CLI 产物。

旧任务如果创建于封面持久化功能加入之前，任务列表可能仍没有封面；重新解析并创建任务后会保存新的封面和时长信息。
